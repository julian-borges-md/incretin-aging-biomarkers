## 4. Lessons worth remembering

### The root pattern: a uniform error looks like no error

Three failures shared one shape. Something was wrong everywhere at once, so nothing looked inconsistent, and every check agreed with the thing it checked.

- The composite's direction convention inverted every lower-is-better biomarker. Every biomarker was lower-is-better, so it flipped together and looked fine until adiponectin arrived.
- `validate_pipeline` Test 4 existed to check direction and passed, because all its cases used positive effects and `+1` directions.
- The GDF-15 claim joined two accurate within-arm results from different trials. Neither source was wrong.

**Standard extension adopted:** a check that encodes the same assumption as the thing it checks cannot fail in the way that matters. Every convention needs a case that breaks if the convention is inverted.

### Evidence synthesis

- Within-arm changes from different trials are not a contrast. No common control, no inference.
- Read the column next to the one you care about. The saturation claim died on the weight column.
- Check PMC before declaring a paywall. Six of the best papers were open after I generalised from one failure.
- A p-value reported as a bound carries no recoverable variance.
- Comparator choice confounds class contrasts. Glimepiride causes weight gain; 34 of 40 mono trials are active-controlled while all dual and triple rows are placebo-controlled.

### Engineering

- Atomic writes for any in-place rewrite. A crash cost rows twice.
- Transformations must be idempotent. Set from a canonical map, never flip.
- Never let per-file type inference decide column types across a merge.
- **A script must never ingest its own downstream output.** Exclude by prefix, not by exact filename.
- Delegate CSV quoting to the parser. My hand-rolled ragged-row check flagged correctly quoted commas.

### Process

- Register before touching any trial data.
- Require only what the analysis needs, where it needs it.
- Never hardcode an interpretation a script can compute.
- **Check the existing skill file before improvising.** The Web of Science route was already documented and I invented a federation path instead.

### What worked and should be preserved

- Extracting rather than citing: four extractions, three errors found in our own work.
- Writing criteria before grading. The surrogacy appraisal cannot be accused of fitting.
- Running gates rather than recalling them. It caught the broken build during this very review.
- Reporting withdrawn claims in commit messages, so the history carries the reasoning.

## 5. Room for improvement

### Mistakes I made, named

| Mistake | Cost |
|---|---|
| Invented a federation sign-in path without checking the documented route | A session of wasted effort |
| Diagnosed missing entitlement from a partial view | Wrong conclusion stated confidently |
| Generalised from one paywalled paper to "full text is the hard blocker" | Delayed finding six open-access papers |
| Fabricated baseline means (ALT 28, AST 23, GGT 34, FLI 77) while writing the converter | Caught before running. Would have rescaled four real effects into invented percentages |
| Non-atomic rewrite script | Lost rows twice |
| Hand-rolled CSV quoting | False positive blocked a build |
| Let `build_master` ingest its own output | Silent until this review |
| Over-read "focus on action not mechanism" as a rescoping instruction | Started dismantling a scope that was fine |

### The pattern underneath

Two distinct failure modes, both mine:

**Concluding before checking.** The paywall generalisation, the entitlement diagnosis, the federation path, the hardcoded interpretation. In each case the information needed was one call away.

**Fabricating plausible values.** The baseline means are the serious one. They looked entirely reasonable and no source supplied them. This happened once and was caught; the correction now sits in the converter as a comment so the next reader sees it.

### Self-correction adopted

Before asserting any factual claim about state, run the command. This SIRLP applied that rule and immediately found a broken build.
